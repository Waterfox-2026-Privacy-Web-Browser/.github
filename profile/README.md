# Project Overview

Waterfox is a privacy-focused web browser based on Mozilla's Gecko browser engine. It provides a customizable desktop browsing experience while retaining compatibility with modern websites and supporting extensive interface configuration.

Waterfox is available for Windows, macOS, Linux, and Android, with desktop builds available for x64 and ARM64 platforms. The current desktop release is **Waterfox 6.7.4**, released on September 22, 2026.

---

# Privacy & Content Blocking

Waterfox includes privacy-oriented settings and built-in content-blocking functionality.

The browser provides controls for tracking protection, cookies, JavaScript, referrer policies, WebRTC, and other privacy-related browser behavior.

The built-in ad blocker was enabled by default during the 6.6 series and continued to receive improvements in subsequent releases.

Waterfox also includes controls for search suggestions and AI-generated search results, with the latest 6.7.4 release adding an option to disable AI answers in search results.

---

# Tabs & Interface Customization

Waterfox provides extensive interface customization options for users who want more control over their browser layout.

Version 6.7 introduced the **Nova** browser style alongside Proton and Photon, as well as twelve color palettes with light and dark variants.

Version 6.7.1 restored more than 120 interface customization options and added additional controls for tabs, toolbars, bookmarks, icons, themes, content, and the video player.

---

# Tree Tabs & Vertical Sidebar

Waterfox 6.7 introduced native tree-style tabs as part of its vertical tab system.

Users can organize tabs into hierarchical trees and groups, making large browsing sessions easier to manage.

The 6.7.2 release improved tree restoration, tab dragging, ordering, pinned tabs, sidebar behavior, and split-view handling.

Waterfox 6.7.4 also includes improvements related to the vertical-tab experience and restores additional browsing functionality such as RSS and Atom feed discovery.

---

# Extensions & Compatibility

Waterfox supports modern Firefox-compatible extensions and provides additional compatibility features for older extension technologies.

Waterfox 6.7 restored support for several categories of legacy extensions, including restartless, overlay-based, and restart-required add-ons.

The browser also maintains compatibility with modern web standards through its Gecko-based browser engine.

---

# 2026 Updates

The latest desktop release is **Waterfox 6.7.4**, published September 22, 2026. It includes:

* RSS and Atom feed discovery.
* An option to disable AI answers in search results.
* Search suggestion controls.
* A Windows media-key overlay option.
* JPEG-XL decoder updated from 0.6.0 to 0.7.4.
* Removal of an older weak encryption cipher.
* Removal of the bundled ONNX runtime.

The major **6.7 "Supernova"** release moved Waterfox from Gecko ESR 140 to **Gecko ESR 153**, bringing a year's worth of upstream engine, performance, and security improvements. It also introduced native tree tabs, Nova styling, additional color palettes, a redesigned ad-blocker panel, legacy-extension support, and ARM64 desktop builds.
